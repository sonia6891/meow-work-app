# iOS App Store 商品頁素材規格（2026）

目標：為《喵的，又要上班了》建立可重複產生、符合 Apple 規範的 iPhone App Store 截圖流程。

## 基準
- 主輸出：6.9 吋 iPhone，直向 1320 × 2868 px。
- 格式：PNG，無 Alpha／透明度。
- 截圖必須展示 App 真實使用中的 UI，不使用登入頁、啟動畫面或純品牌圖取代功能畫面。
- 使用虛構示範帳號與虛構薪資／班表資料，不放真實個資。
- 狀態列：09:41、Wi-Fi 滿格、行動網路滿格、電量 100%。
- 若 App 支援深色模式，至少保留一張深色介面成品。
- 第一至第三張優先傳達核心價值，因為沒有 App Preview 時可能出現在搜尋結果。

## 正式 8 張順序
1. **排班、薪資、生活，一個地方搞定**
   - 畫面：總覽首頁。
   - 重點：今天安排、待辦、班別與重要提醒同時可讀。
2. **今天上什麼班，一眼就知道**
   - 畫面：排班／輪班日曆。
   - 重點：班別、日期、國定假日資訊。
3. **加班、請假、待辦，不再靠記憶**
   - 畫面：行程與待辦／加班請假紀錄。
4. **薪水有沒有算對，直接幫你對**
   - 畫面：薪資對帳免費版。
   - 重點：公司實際入帳、App 實領、本月差額。
5. **薪資對帳 Pro，連細節一起檢查**
   - 畫面：Pro 薪資辨識／交叉檢查。
   - 不宣稱尚未在正式版提供的能力。
6. **有事直接跟喵助理說**
   - 畫面：喵助理。
   - 展示真實可執行的語音／文字工作流程。
7. **勞基法問題，也能直接問**
   - 畫面：勞基法問答。
   - 文案避免暗示法律意見或官方法律服務。
8. **你的工作生活，終於不用亂成一團**
   - 畫面：品牌收尾，但仍保留真實 App UI。

## 視覺規則
- 不套錯誤 iPhone 外框；若使用裝置框，型號、Dynamic Island、圓角與畫面比例必須一致。
- 標題放在安全區，不遮住重要 UI。
- 每張只講一個主要利益點；手機 UI 必須是視覺主體。
- 不放競品名稱、Android／Google Play 圖像。
- 不放價格或無法驗證的「第一／最好／最準」等宣稱。
- Pro 畫面清楚標示 Pro，避免免費／付費功能混淆。

## App Preview
- 建議 20–25 秒，全部使用 App 內實際畫面。
- 0–4s：總覽／排班。
- 4–9s：行程、待辦、加班。
- 9–14s：薪資對帳。
- 14–20s：喵助理。
- 20–25s：品牌收尾＋真實 UI。
- 不拍手持手機或真人操作裝置；可加旁白與文字 overlay。

## 驗收 Gate
- [ ] 8 張皆為 1320×2868。
- [ ] 無 Alpha。
- [ ] 狀態列一致。
- [ ] 無真實個資。
- [ ] 所有功能均存在於送審版本。
- [ ] Pro／免費功能標示一致。
- [ ] 第一至第三張在縮圖尺寸仍能讀懂。
- [ ] 無 Android／競品元素。
- [ ] 截圖與 App Review build 實際 UI 一致。
